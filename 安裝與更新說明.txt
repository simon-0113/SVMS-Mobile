SVMS Mobile｜店家資訊卡網頁版 1.0

【目前功能】
- 手機與電腦瀏覽器皆可使用。
- 店名完整查詢、部分名稱查詢、711／FM／HL 名稱變體。
- GT查核總表與GT巡店總表分區顯示。
- CVS 店家資訊卡。
- 查核與巡店陳列／分布差異。
- 最近巡店歷程。
- 顯示正式索引更新時間。

【本機預覽】
因瀏覽器安全限制，不可直接雙擊 index.html。
請在本資料夾執行：

python -m http.server 8080

再以瀏覽器開啟：

http://localhost:8080

【更新網頁資料】
先確保 Query Engine 已重建 stores_index.json，再將：

Query Engine/cache/stores_index.json

複製覆蓋到：

SVMS_Mobile_店家資訊卡/data/stores_index.json

也可以使用：

python publish_index.py --query-engine "你的 Query Engine 資料夾路徑" --refresh

【重要：正式部署前】
這份索引包含公司店家資料，不建議直接部署成公開網站。
正式上線應使用有登入或存取控制的私人網站。
